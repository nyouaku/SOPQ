Bagus! Backend image berhasil di-build. Sekarang langkah-langkahnya untuk mencoba di HP:

1. Start Semua Services

cd D:\aldeb\project\project_21\stock-opname-app
docker compose up -d

2. Cek Status Services

docker compose ps

Pastikan semua services running (postgres, redis, backend, dashboard, nginx).

3. Cari IP Address Komputer Anda

ipconfig

Cari IP Address di bagian IPv4 Address (biasanya 192.168.x.x)

4. Setup Flutter App untuk Connect ke Backend

Edit file mobile/lib/core/constants/app_constants.dart:

static const String apiBaseUrl = 'http://192.168.x.x/api/v1'; // Ganti dengan IP komputer Anda

Atau jika langsung ke backend tanpa nginx:

static const String apiBaseUrl = 'http://192.168.x.x:8080/api/v1';

5. Build & Install Flutter App ke HP

Pastikan HP dan Komputer dalam satu WiFi yang sama!

cd mobile
flutter pub get
flutter run

Atau build APK untuk install manual:

flutter build apk --release

File APK ada di: mobile/build/app/outputs/flutter-apk/app-release.apk

Transfer file APK ke HP dan install.

6. Firewall Windows (PENTING!)

Buka port agar HP bisa akses backend:

# Buka port 8080 (backend)
netsh advfirewall firewall add rule name="Stock Opname Backend" dir=in action=allow protocol=TCP localport=8080

# Buka port 80 (nginx)
netsh advfirewall firewall add rule name="Stock Opname Nginx" dir=in action=allow protocol=TCP localport=80

7. Test dari HP

- Buka browser HP, akses: http://192.168.x.x (dashboard web)
- Buka Flutter app, login dengan:
  - Username: staff
  - Password: staff123

Jika berhasil login, Anda bisa langsung scan QR Code!

---
Troubleshooting:

Jika HP tidak bisa connect:
1. Pastikan HP dan komputer dalam WiFi yang sama
2. Ping dari komputer ke HP atau sebaliknya
3. Cek firewall Windows sudah allow port 80 dan 8080
4. Restart Docker services: docker compose restart
